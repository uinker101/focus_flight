# Focus Flight

离线专注飞行网站：从香港出发，按真实来源的参考班表（每周循环）选择航班，值机时写下这一程要完成的目标清单，候机、飞行，落地时目标全部完成就出票，收集登机牌、航空公司、机型和机场。规划见 [PLAN.md](PLAN.md)，数据格式见 [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)。

## 启动

双击 `Focus Flight.command`，或在终端运行：

```bash
python3 server.py
```

浏览器打开 http://localhost:8742/ 。日常使用不需要联网，也不需要安装任何依赖（只用 macOS 自带的 Python 3 和浏览器）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `server.py` | 本地服务：静态文件、存档读写、关页暂停、导入导出 |
| `app/` | 网站（HTML/CSS/原生 JS 模块，无构建步骤） |
| `app/packs/` | 编译好的航班数据包，`index.json` 指定当前版本 |
| `app/assets/map/world.json` | 离线地图（Natural Earth 1:50m，公有领域） |
| `app/assets/aircraft/` | 跟随视角的 3D 飞机模型（FlightGear，GPLv2，来源和转换方法见目录内 README） |
| `app/vendor/three/` | Three.js r170 及用到的扩展（MIT），只在打开“跟随飞机”时加载 |
| `data/` | 数据包的原料：参考表、来源、班表 CSV、待核对清单 |
| `tools/` | 提取、校验、编译数据的脚本 |
| `userdata/` | 个人存档和自动备份（不进 git） |

## 更新数据包

```bash
python3 -I tools/build_pack.py --version <新版本号> --title "<名称>"
```

会校验 `data/schedules/*.csv`，生成 `app/packs/<版本>.json` 并设为当前版本，被拒绝的行写到 `data/review/`。旧数据包文件保留，已完成旅程保存了当时的航班快照，换数据包不会改动旧登机牌和收藏。

别人给的数据包 JSON 也可以在网站“设置 → 数据包 → 导入数据包”里安装：导入前会显示班表、机场、航司、机型依据的变更摘要；装好的版本可以随时切换，也就是回退。

## 演示模式

设置里打开“演示模式”后，登机口有“立即出发”，飞行界面有 ×30 / ×120 加速，方便测试完整流程。用过加速的旅程，登机牌会盖“演示加速”章。
