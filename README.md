# Focus Flight

离线专注飞行网站：从香港出发，按真实来源的参考班表（每周循环）选择航班，值机时写下这一程要完成的目标清单，候机、飞行，落地时目标全部完成就出票，收集登机牌、航空公司、机型和机场。规划见 [PLAN.md](PLAN.md)，数据格式见 [docs/DATA_FORMAT.md](docs/DATA_FORMAT.md)。

## 启动

双击 `Focus Flight.command`。第一次运行会先下载离线地图（约 900 MB，只需要一次；中断了重新双击会接着下），之后启动网站。也可以在终端运行：

```bash
python3 tools/fetch_map.py
```

```bash
python3 server.py
```

浏览器打开 http://localhost:8742/ 。地图下载好以后，日常使用不需要联网，也不需要安装任何依赖（只用 macOS 自带的 Python 3 和浏览器）。

## 目录

| 路径 | 内容 |
| --- | --- |
| `server.py` | 本地服务：静态文件、存档读写、关页暂停、导入导出 |
| `app/` | 网站（HTML/CSS/原生 JS 模块，无构建步骤） |
| `app/packs/` | 编译好的航班数据包，`index.json` 指定当前版本 |
| `app/assets/map/` | 离线地图，由 `tools/fetch_map.py` 下载（不进 git），见下面“离线地图” |
| `app/assets/aircraft/` | 跟随视角的 3D 飞机模型（FlightGear，GPLv2，来源和转换方法见目录内 README） |
| `app/vendor/maplibre/` | MapLibre GL JS 6.16（BSD-3），画飞行地图和收藏里的地球仪 |
| `app/vendor/three/` | Three.js r170 和 glTF 加载器（MIT），只在跟随视角显示 3D 模型时加载 |
| `data/` | 数据包的原料：参考表、来源、班表 CSV、待核对清单 |
| `tools/` | 提取、校验、编译数据的脚本 |
| `userdata/` | 个人存档和自动备份（不进 git） |

## 离线地图

`tools/fetch_map.py` 从下面三个全球数据里只读取低缩放级别（HTTP 分段读取，不会下载整个文件），存成 `app/assets/map/` 下的 MBTiles 文件，由 `server.py` 以 `/tiles/...` 提供给网页：

| 文件 | 内容 | 缩放级别 | 大小 | 来源与许可 |
| --- | --- | --- | --- | --- |
| `base.mbtiles` | 矢量底图：海岸线、河流湖泊、地表植被、公路、边界、中文地名 | z0–8 | 约 580 MB | [Protomaps](https://docs.protomaps.com/basemaps/downloads) 每日构建，© OpenStreetMap 贡献者（ODbL） |
| `terrain.mbtiles` | 高程，用来画山体阴影 | z0–6（512 像素瓦片） | 约 280 MB | [Mapterhorn](https://mapterhorn.com/attribution) |
| `lights.mbtiles` | 夜晚城市灯光 | z0–5 | 约 33 MB | NASA Black Marble 2016（经 NASA GIBS，公有领域） |
| `fonts/` | 拉丁字母标签字形（中文用系统字体） | | 约 2 MB | Noto Sans（OFL），取自 protomaps/basemaps-assets |

地图配色在 `app/js/basemap.js`：底图始终是浅色（苹果地图风格），哪里是夜晚按当前太阳位置离线计算，从太阳在地平线上 3° 到地平线下 8° 平滑变暗（地面上约 1200 公里），天黑后城市灯光亮起，每 2 分钟更新一次。界面的日夜主题仍然跟随现实所在地。

想换更新的底图或改缩放级别：改 `tools/fetch_map.py` 顶部的常量，删掉对应的 `.mbtiles` 再运行脚本。`python3 tools/fetch_map.py --sizes` 只读目录，打印每个缩放级别的大小。

## 更新数据包

```bash
python3 -I tools/build_pack.py --version <新版本号> --title "<名称>"
```

会校验 `data/schedules/*.csv`，生成 `app/packs/<版本>.json` 并设为当前版本，被拒绝的行写到 `data/review/`。旧数据包文件保留，已完成旅程保存了当时的航班快照，换数据包不会改动旧登机牌和收藏。

别人给的数据包 JSON 也可以在网站“设置 → 数据包 → 导入数据包”里安装：导入前会显示班表、机场、航司、机型依据的变更摘要；装好的版本可以随时切换，也就是回退。

## 演示模式

设置里打开“演示模式”后，登机口有“立即出发”，飞行界面有 ×30 / ×120 加速，方便测试完整流程。用过加速的旅程，登机牌会盖“演示加速”章。
