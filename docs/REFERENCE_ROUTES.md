# 离线参考航路

## 计划与执行 proposals（2026-11-07）

用户选择：真实导航点／航路网规划的离线参考航路，允许与某天实际飞行不同。

覆盖基线是 `global-202611.stable1` 的全部 14,959 条班表、4,135 个有方向的机场组合、706 个机场。去程和回程分别生成。既有收藏地图继续表达旅行网络；本次修改飞行中的路径、位置、朝向和距离。

1. 数据：保留 FlightGear 原始导航数据及许可，为每个航路点、已发布航路段保留出处。建立全量班表到航路的映射及可重复生成的覆盖报告。
2. 规划：优先沿航路网飞行；机场接入、网络缺口和洋区使用真实导航点之间的 DCT 参考连接。DCT 是本项目规划的连接，不宣称是已发布航路、SID/STAR 或管制许可。
3. 运行：同一个累计航路距离驱动飞机、地图已飞／未飞线、剩余距离、地速和朝向；值机快照保存本程航路，刷新和暂停续飞沿用它。
4. 验收：全量检查覆盖、来源、端点、连续性及距离；抽查短途、跨洋、日期变更线和全部地图视角；使用独立测试存档。

## 来源和真实性范围

- [FlightGear FGData / Navaids](https://gitlab.com/flightgear/fgdata/-/tree/next/Navaids)：`awy.dat.gz`、`nav.dat.gz`、`fix.dat.gz`，文件头的数据周期均为 **2013.10**，© 2013 Robin A. Peel，GPL-2.0-or-later。
- 下载日期：2026-11-07。原始文件保留在 `data/navigation/`，构建产物记录 SHA-256，可离线复现。
- 这是历史导航数据上的模拟参考飞行计划。数据没有当日风场、临时空域限制、航司放行、跑道选择或进离场程序，也不能据此声称某个班号实际飞过这条路径。
- 旧格式航路文件没有单向字段，本项目按双向网络规划；去回程不能理解为现实中均可使用的航路许可。
- DCT 连接会在航路详情列出。不得通过随机偏移坐标或对 A→B 大圆加弯曲生成“真实”航路。
- 唯一的短途机场参考补充为 **RBV→EGM（Ramata→Seghe）**：其约 52 公里的航段若强行经过历史库最近的 MUNDA 点会绕至约 119 公里。使用 [Ramata 跑道](https://www.openstreetmap.org/way/552956950) 和 [Seghe 跑道](https://www.openstreetmap.org/way/205611143) 的真实端点作 DCT 地理参考，单独显示“机场地理参考”。原始节点坐标、版本、日期和提取依据保存在 `data/navigation/airfield_routes.json`。这不代表实际跑道选择或已发布的进离场程序；地图数据 © OpenStreetMap contributors，按 [ODbL](https://www.openstreetmap.org/copyright) 提供。

## 生成方式

`python3 tools/build_routes.py` 用系统 Python 离线生成约 1.5 MB 的运行时航路表，不在浏览器中运行寻路算法。使用有距离权重的最短路径，轻度优先原始航路段；DCT 补连附近的实际导航点，洋区使用原始文件中的坐标点和命名点。每个机场匹配附近候选点，避免固定接入某个方向造成绕行。海洋连接不是每日 NAT/PACOTS 航迹。

报告保留每条路线的距离、大圆距离比、DCT 里程与两端接入距离，便于检查。历史资料稀疏的地区可能有较长 DCT 段；这属于参考规划的限制，不能解释为当前航空运行许可。

## 完成标准

全部 14,959 条当前班表都能解析到有来源的参考航路（其中一条短途机场组合使用上述机场端点参考）；缺失数量为零；地图与模拟使用相同的累计距离。只完成样例、仅增加曲线或静默退回机场间大圆均不算当前数据集完成。
